# Player images

Convention: `/players/<player-id>.jpg`, matching each player's `id` in
[`src/game/data/players.ts`](../../src/game/data/players.ts) and the
`imageUrl` field already set on every player record.

## Licensing requirement — read before adding any file here

This project may eventually be published publicly. **Do not add a player
photograph to this directory unless its license or usage permission for
public redistribution has been explicitly verified.** This includes (but
is not limited to) images sourced from Google Images, Getty Images, ESPN,
FIFA, UEFA, club websites, social media, or any other site where
redistribution rights are unclear.

Until an image is verified and added, `PlayerAvatar`
(`src/game/components/PlayerAvatar/PlayerAvatar.tsx`) automatically shows a
styled initials fallback instead — this is expected, not an error.
